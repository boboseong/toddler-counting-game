# 🎈 숫자 놀이터

두세 살 아이와 함께 **하나, 둘, 셋** 을 세어 보는 한국어 수 세기 놀이입니다.
벌점이 없고, 틀리면 병아리가 같이 다시 세어 줍니다. 라운드를 마칠 때마다 별을 모으고, 별 3개마다 새 스티커 친구가 찾아옵니다.

**👉 바로 놀기: https://boboseong.github.io/toddler-counting-game/**

폰이나 태블릿에서 열고 "홈 화면에 추가" 하면 전체 화면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.

## 놀이

| 놀이 | 내용 |
| --- | --- |
| 🍎 톡톡 세기 | 물건을 하나씩 누르며 센다 |
| 🔢 몇 개일까? | 물건 개수를 보고 숫자를 고른다 |
| 🐰 냠냠 먹이 주기 | 동물이 달라는 만큼 먹이를 준다 (4단계부터는 "다 줬어요"까지) |
| 🫧 거품 팡팡 | 올라오는 거품을 터뜨리며 센다 (다른 놀이의 가장 큰 수까지) |
| 🔍 숫자 찾기 | 풍선·별·알·구름에 숨은 숫자 중에서 "숫자 5를 찾아줘" 하고 말한 숫자를 누른다. 틀리면 "이건 숫자 1이야. 숫자 5를 찾아줘!" 하고 다시 묻는다 |
| 🛗 딩동 엘리베이터 | 엘리베이터에 탄 동물 친구가 "오 층 눌러 주세요!" 하면 그 층 버튼을 누른다. 올라가는 동안 "일, 이, 삼, 사, 오!" 하고 층을 같이 세고, 틀린 층을 누르면 그 층까지 가서 문이 열리고 "여기는 삼 층, 토끼네 집이야!" 하고 그 층 친구가 인사한 뒤 다시 부탁한다 (아래 참고) |
| 📱 숫자 따라 누르기 | 전화기 키패드(1~9, 별·0·샵, 지우기)에서 병아리가 "일과 이를 눌러줘!" 하고 말한 번호를 보고 들으며 누른다. 다 누르면 초록 전화 버튼을 눌러 동물 친구에게 전화를 건다 (아래 참고) |
| 🎠 빙글빙글 | 일곱 놀이가 차례로 바뀌는 모드. 아이의 관심이 식기 전에 장면을 바꿔 준다 (아래 참고) |

### 🎠 빙글빙글이 놀이를 바꾸는 기준

- 순서는 톡톡 세기 → 숫자 따라 누르기 → 몇 개일까? → 거품 팡팡 → 딩동 엘리베이터 → 냠냠 먹이 주기 → 숫자 찾기. 집중이 많이 필요한 놀이 사이에 몸으로 노는 놀이를 끼워 긴장과 이완이 번갈아 오게 했고(집중 놀이가 하나 더 많아 숫자 따라 누르기와 몇 개일까는 이어짐), 버튼을 누르는 두 놀이(숫자 따라 누르기·딩동 엘리베이터)는 멀리 떨어뜨렸습니다. 다음에 열면 지난번 다음 놀이부터 이어집니다.
- 놀이는 항상 라운드가 끝난 축하 직후에만 바뀝니다(라운드 도중에 끊지 않음). 칭찬 말이 끝날 때까지 기다렸다가 넘어가고, 그동안 놀이 화면은 다음 라운드를 시작하지 않고 멈춰 있습니다. 넘어가는 조건은 다음과 같고, 부모님 설정에서 빠르기(2번·1분 30초 / 3번·2분 30초 / 5번·4분)를 고를 수 있습니다.
  - 기본: 정해진 횟수만큼 성공 + 최소 시간(보통 1분). 푹 빠져서 잘하고 있을 때 너무 일찍 끊지 않되, 정해진 횟수보다 2번 더 성공하면 그때는 넘어갑니다.
  - 톡톡 세기·거품 팡팡은 세기만 하면 무조건 성공이라 최소 시간 없이 빠르게 넘어갑니다(빠르게 1번 / 보통 2번 / 천천히 3번 성공).
  - 정해진 시간(보통 2분 30초)이 지나면 성공 횟수가 모자라도 다음 성공 직후에 넘어갑니다.
  - 두 번 어려워하면(오답·과식 등 실패 신호) 다음에 성공하자마자 넘어갑니다. 성공한 기분으로 끝내고 장면을 바꿉니다.
  - 35초 동안 아무것도 안 누르면 흥미를 잃은 것으로 보고 "다른 놀이 해 볼까?" 하며 바꿉니다.
  - 막 누르기가 반복돼 라운드가 끝나지 않아도 5분이 지나면 넘어갑니다.
- 바뀔 때는 병아리가 "이번엔 거품 팡팡!" 하고 다음 놀이 아이콘이 튀어나오는 전환 화면이 나옵니다. 말이 끝나면 **시작!** 버튼이 나오고, 눌러야 다음 놀이가 시작됩니다(앞 단계 소리와 겹치지 않음). 10초 동안 안 누르면 저절로 시작합니다. 놀이 중에는 위쪽에 순서 띠(현재 놀이와 성공 횟수)가 보입니다. 띠를 길게 누르면 바로 다음 놀이로 갑니다.

- 숫자는 1부터 19까지(엘리베이터는 20층까지) 다룹니다. 문제를 푸는 놀이(몇 개일까·먹이 주기·숫자 찾기·딩동 엘리베이터·숫자 따라 누르기)마다 단계가 따로 있고, 3번 연속 성공하면 한 단계 올라가고 2번 연속 어려워하면 내려갑니다.
  - 톡톡 세기·거품 팡팡: 문제를 푸는 단계가 없어서(세기만 하면 끝나므로) 따로 단계를 두지 않고, 몇 개일까 · 먹이 주기 · 숫자 찾기에서 지금 나오는 **가장 큰 수**에 맞춥니다. 거품 팡팡은 그 수까지 세고, 톡톡 세기는 그 수 이하에서 냅니다(5를 넘으면 위쪽 60% 정도).
  - 먹이 주기: 8단계 (1~3 → 1~4 → 1~5 → … → 11~19)
  - 몇 개일까?: 다른 놀이보다 어려워서 14단계로 잘게 나눴습니다. 보기 2개 → 3개, 범위 1~3 → 10~19, 마지막 단계는 정답과 1~2 차이 나는 "비슷한 수"만 보기로 나옵니다.
  - 딩동 엘리베이터: 5단계. 1~5층(노란 빛) → 1~5층 → 1~10층 → 1~15층 → 1~20층. 첫 단계만 정답 버튼에 노란 빛을 비추고 말풍선에도 층 숫자가 나오며, 그다음부터는 소리만 듣고 누릅니다. 두 번 틀리거나 한참 가만히 있으면 그때만 노란 빛과 숫자로 도와줍니다. 톡톡 세기·거품 팡팡이 따라가는 "가장 큰 수"에는 넣지 않습니다.
  - 숫자 찾기: 12단계. 보고 찾기(말풍선에 숫자를 보여 줌) → 듣고 찾기(소리만) → 세어서 찾기("다섯 개를 뜻하는 숫자") 순서로, 흩어진 숫자는 3개에서 9개까지 늘어납니다. 두 번 틀리거나 한참 가만히 있으면 정답이 살짝 커졌다 작아지며 힌트를 줍니다.
  - 숫자 따라 누르기: 9단계. 누를 자리 수로 나눕니다(가장 큰 수에는 영향을 주지 않음).
    1. 두 자리 + 다음에 누를 버튼이 노랗게 빛남
    2. 두 자리
    3. 세 자리
    4. 세 자리 + 별·샵이 꼭 하나
    5. ~ 9. 네 자리 → 다섯 → 여섯 → 일곱 → 여덟 자리 (별·샵이 절반쯤 하나 섞임)

### 📱 숫자 따라 누르기

- 위에 누를 번호가 크게, 그 아래에 누른 번호가 들어가는 칸이 자리마다 맞춰 있고, 맨 아래는 전화기 키패드(1~9 / 별·0·샵 / 전화·지우기)입니다. 버튼 숫자 색과 위쪽 번호 색이 같아서 색으로도 찾을 수 있습니다.
- 번호는 한 자리씩 읽습니다. 두 자리는 "일과 이를 눌러줘!", 세 자리부터는 "일, 이, 삼을 눌러줘!". 0은 "영", \*은 "별", #은 "샵". 누를 때마다 진짜 전화기 버튼 소리(DTMF)와 함께 그 숫자 이름을 말해 주고, 말풍선을 누르면 다시 들려줍니다.
- 틀린 버튼을 누르면 그 숫자가 빨갛게 칸에 들어가고 지우기 버튼이 빛나며 "어? 다른 버튼이네! 지우기를 눌러 볼까?" 합니다. 지울 때까지 다음 숫자는 받지 않습니다. 두 번 틀리면 다음 버튼을 노랗게 알려 줍니다.
- 다 누르면 초록 전화 버튼이 두근거리고, 누르면 따르릉 소리 뒤에 동물 친구(모은 스티커 동물도)가 "여보세요? 나 토끼야! 전화해 줘서 고마워!" 하고 받습니다. 번호를 다 누르기 전에 누르면 "아직 다 안 눌렀어!" 하고 다음 버튼을 노랗게 알려 줍니다.
- 8초 동안 아무것도 안 누르면 지금 할 일(다음 숫자 / 지우기 / 전화 버튼)을 다시 알려 줍니다.
- 수가 5개를 넘으면 5개씩 줄을 맞춰 보여 줘서 묶어 세기 연습이 됩니다.
- 안내 음성이 나오는 동안(👂 표시)에는 눌러도 세지 않고, 세는 탭 사이에는 최소 간격(기본 0.7초, 설정에서 조절)이 있어 막 눌러서는 진행되지 않습니다.
- 막 눌러서 끝낸 라운드는 별을 주지 않고 거북이가 "천천히, 하나씩!" 하고 같은 라운드를 다시 냅니다.
- 효과음과 한국어 음성 안내를 켜고 끌 수 있습니다. 음성은 Gemini TTS 로 미리 만든 파일을 쓰고, 파일이 없으면 브라우저 TTS 로 읽습니다 (아래 "음성 만들기").
- 레벨이 올라가면 🚀 "우와, 더 큰 숫자 도전!" 배지가 잠깐 뜹니다. 내려갈 때는 조용히 바뀝니다.

### 🛗 딩동 엘리베이터

- 동물 친구 스티커북 순서대로 한 층에 한 친구씩 늘 같은 층에 삽니다: 1층 병아리(로비) · 2층 사자 · 3층 토끼 · 4층 판다 · 5층 여우 · 6층 개구리 · 7층 코알라 · 8층 유니콘 · 9층 문어 · 10층 펭귄 · 11층 나비 · 12층 돌고래 · 13층 공룡 · 14층 거북이 · 15층 홍학 · 16층 고래 · 17층 부엉이 · 18층 호랑이 · 19층 소 · 20층 돼지. 복도 문패에도 그 친구 얼굴이 있습니다.
- 손님은 늘 1층에서 탑니다. "사자가 탔어요!" → 손님이 "이 층 눌러 주세요!" → 누르면 문이 닫히고 표시판이 한 층씩 올라가며 "일, 이" 하고 센 뒤 딩동, "이 층입니다!", 손님이 내려서 "우리 집이다! 고마워!" → 1층으로 슝 내려와 다음 손님.
- 10층 이상으로 올라갈 때는 한 낱말씩 끊지 않고 "일 이 삼 … 십", "십일 십이 … 십오" 를 이어서 빠르게 셉니다(15층까지 약 9초, 20층까지 약 12초). 표시판도 그 말에 맞춰 올라갑니다. 10층보다 낮을 때와 내려갈 때는 한 층씩 천천히 셉니다.
- 틀린 층을 누르면 그 층까지 실제로 가서(더 위로 갔으면 내려오며 거꾸로 셉니다) 그 층 친구가 인사하고, 손님이 "여기가 아니에요!" 하고 다시 부탁합니다. 엘리베이터는 그 층에서 다시 출발합니다.
- 버튼판은 진짜 엘리베이터처럼 1층이 맨 아래이고 위로 갈수록 큰 수입니다(5층까지는 한 줄, 그 위는 두 줄. 세로가 짧은 가로 화면에서는 버튼이 작아지지 않게 줄을 늘립니다).
- **외우기**: 다섯 번 이상 집에 데려다 준 친구는 노란 빛이 없는 단계에서 가끔(1/10) 층을 말하지 않고 "우리 집에 데려다 줘!" 합니다. 한참 가만히 있거나 틀리면 "우리 집은 오 층이에요!" 하고 알려 줍니다. 외우기 문제에서 틀린 것은 단계를 내리는 실패로 치지 않습니다.
- 손님을 누르면 부탁을 다시 들려줍니다.

## 자체 제작 그림과 리액션

- 캐릭터·물건·배경 소품은 이모지 대신 코드로 그린 SVG 입니다(`src/art`). 기기마다 모양이 같고, 눈·입·팔·날개를 따로 움직여 표정이 바뀝니다.
  - 병아리: 누른 곳을 쳐다보고, 안내할 땐 말하는 입, 정답이면 파닥파닥 폴짝, 틀리면 갸우뚱, 오래 가만히 있으면 꾸벅꾸벅.
  - 먹이 주기 동물: 기다릴 땐 입을 벌리고, 먹이가 입으로 날아가면 냠냠, 배가 조금씩 불러 오고, 너무 많으면 볼이 빵빵.
  - 셀 물건: 물건마다 움직임이 달라요(사과 통통, 자동차 부릉, 물고기 파닥, 꽃 활짝 …). 세면 웃고, 셀수록 반짝이가 많아집니다.
  - 장면: 흘러가는 구름, 해·달, 나무·바구니·해바라기·조개·게를 누르면 반응합니다(세기와는 상관없음).
  - 스티커 친구 72종(동물·탈것·숲속), 거품 속 바다 친구, 놀이 아이콘과 버튼·안내 표시(홈·귀·손가락·스티커북·설정 등)까지 모두 그림입니다.
- 데이터에는 이모지를 적고, 화면은 `Glyph` 로 그립니다. `src/art/registry.ts` 에 등록된 이모지는 모든 화면에 그림으로 나오고, 등록하지 않은 새 이모지만 이모지 그대로 나옵니다.
- `?gallery` 를 붙여 열면 모든 그림을 표정별로 볼 수 있습니다.
- 누를 때 짧은 진동(지원 기기만)은 부모님 설정에서 끌 수 있고, 기기의 "동작 줄이기" 설정을 따르면 흔들림·날아가기는 생략됩니다.

## 흥미를 이어 가는 장치

- **축하가 매번 달라요**: 컨페티 · 풍선 날리기 · 별비 · 하트 중 하나가 돌아가며 나오고, 칭찬 말도 13가지입니다. 가끔(약 1/6) **보너스 별**이 떠서 별을 2개 받습니다.
- **별 항아리**: 숫자 대신 다음 스티커까지 별 3칸이 차오르고, 한 칸 남으면 빈 칸이 두근거립니다.
- **빈 곳을 눌러도 반짝**: 버튼이 아닌 곳을 누르면 반짝이·꽃이 피어나고 작은 소리가 납니다(세기와는 상관없음).
- **놀이마다 다른 장면**: 과수원(톡톡) · 피크닉(몇 개일까) · 농장(먹이 주기) · 바닷가(거품) · 저녁 하늘(숫자 찾기) · 민트빛 하늘(숫자 따라 누르기).
- **스티커 친구가 같이 놀아요**: 가장 최근에 받은(또는 스티커북에서 고른) 친구가 놀이 화면 왼쪽 아래에서 구경하다가 성공하면 박수를 칩니다. 모은 동물 친구는 먹이 주기에 손님으로 찾아옵니다("사자가 놀러 왔어!").
- **스티커북 꾸미기**: 스티커를 누르면 위쪽 장면에 폴짝 붙고(최대 10), "같이 세기"를 누르면 붙인 친구를 하나씩 셉니다.
- 새 스티커 친구는 한 단계씩 나옵니다: 칭찬이 끝나면 🎁 선물 상자와 "선물이 왔어요! 눌러 봐!" → 말이 끝나면 상자를 누를 수 있고, 누르면 새 친구와 이름 → 이름을 다 말하면 **확인** 버튼 → 눌러야 다음 라운드(빙글빙글이면 다음 놀이)로 넘어갑니다. 그동안 뒤의 놀이는 멈춰 있습니다. 버튼이 나온 뒤 10초 동안 아무도 누르지 않으면 저절로 다음 단계로 넘어갑니다.
- **스티커북 3권**: 동물 친구 → 탈것 친구 → 숲속 친구 (모두 72개). 다 모으면 별 3개마다 스티커가 하나씩 **반짝이 스티커**로 바뀝니다.
- **기억하는 인사**: 다시 오면 "어제 만난 여우가 기다리고 있었어!", 오늘 모은 별도 홈에 보여 줍니다.
- **놀이 시간 알림**(부모 설정, 기본 끔 · 10/15/20분): 시간이 되면 다음 성공 직후에 "오늘은 여기까지! 내일 또 만나" 화면에서 오늘 모은 별과 새 친구를 보여 줍니다.

### 음성 만들기 (Gemini TTS · OpenRouter)

앱이 말하는 모든 문장은 `src/lib/phrases.ts` 에 모여 있고(약 2,600문장), 아래 명령으로 음성 파일을 만듭니다.

```bash
GEMINI_API_KEY=... npm run voice:gen   # public/voice/*.mp3 + src/lib/voice-manifest.json
npm run voice:check                    # 빠진 음성 확인
```

- `OPENROUTER_API_KEY` 가 있으면 OpenRouter(`/api/v1/audio/speech`)로 같은 Gemini TTS 를 불러 만듭니다(하루 요청 한도 없음, 사용량만큼 과금). 모델은 `OPENROUTER_TTS_MODEL`(기본 `google/gemini-3.8-flash-tts`)로 바꿀 수 있습니다.
  ```bash
  OPENROUTER_API_KEY=... npm run voice:gen
  ```
- 키는 환경 변수로만 넘기고 파일에 저장하지 마세요.
- 이미 만든 문장은 건너뛰므로 중간에 멈춰도 다시 실행하면 이어서 만듭니다. 문장을 고치면 그 문장만 다시 만듭니다.
- 모델은 `GEMINI_TTS_MODEL`(비우면 가장 최신 TTS 모델), 목소리는 `GEMINI_VOICE_NARRATOR`(병아리) · `GEMINI_VOICE_ANIMAL`(동물 손님)로 바꿀 수 있습니다.
- 자주 나오는 짧은 말은 앱과 함께 미리 받아 두고, 나머지는 한 번 들으면 오프라인에서도 재생됩니다.

기록(별, 스티커, 레벨, 설정, 꾸민 장면, 오늘 기록)은 브라우저 `localStorage` 에만 저장되며 서버로 보내지 않습니다.
