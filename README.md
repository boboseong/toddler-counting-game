# 🎈 숫자 놀이터

두세 살 아이와 함께 **하나, 둘, 셋** 을 세어 보는 한국어 수 세기 놀이입니다.
벌점이 없고, 틀리면 병아리가 같이 다시 세어 줍니다. 라운드를 마칠 때마다 별을 모으고, 별 3개마다 새 스티커 친구가 찾아옵니다.

**👉 바로 놀기: https://boboseong.github.io/toddler-counting-game/**

폰이나 태블릿에서 열고 "홈 화면에 추가" 하면 전체 화면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.

## 놀이

| 놀이 | 내용 |
| --- | --- |
| 🍎 톡톡 세기 | 물건을 하나씩 누르며 센다 |
| 🔢 몇 개일까? | 물건 개수를 보고 숫자를 고른다 |
| 🐰 냠냠 먹이 주기 | 동물이 달라는 만큼 먹이를 준다 (4단계부터는 "다 줬어요"까지) |
| 🫧 거품 팡팡 | 올라오는 거품을 터뜨리며 센다 (다른 놀이의 가장 큰 수까지) |
| 🔍 숫자 찾기 | 풍선·별·알·구름에 숨은 숫자 중에서 "숫자 5를 찾아줘" 하고 말한 숫자를 누른다. 틀리면 "이건 숫자 1이야. 숫자 5를 찾아줘!" 하고 다시 묻는다 |
| 🛗 딩동 엘리베이터 | 엘리베이터에 탄 동물 친구가 "오 층 눌러 주세요!" 하면 그 층 버튼을 누른다. 올라가는 동안 "일, 이, 삼, 사, 오!" 하고 층을 같이 세고, 틀린 층을 누르면 그 층까지 가서 문이 열리고 "여기는 삼 층, 토끼네 집이야!" 하고 그 층 친구가 인사한 뒤 다시 부탁한다 (아래 참고) |
| 📱 숫자 따라 누르기 | 전화기 키패드(1~9, 별·0·샵, 지우기)에서 병아리가 "일과 이를 눌러줘!" 하고 말한 번호를 보고 들으며 누른다. 다 누르면 초록 전화 버튼을 눌러 동물 친구에게 전화를 건다 (아래 참고) |
| 🤲 쏙쏙 나눠 주기 | 아이가 먹이를 여러 개 가지고 있고, 친구가 "당근 세 개 주세요!" 하면 끌어서(또는 톡 눌러서) 준다. 아이 쪽에는 남은 개수만, 친구 쪽에는 "받은 개수 / 달라는 개수"(0/3 → 1/3 → …)가 보인다. **다 줬어요**를 눌러 딱 맞으면 친구가 냠냠 먹고, 많으면 "너무 많아요! 두 개 빼 주세요!", 적으면 "너무 적어요! 한 개 더 주세요!" 하고 차이만큼 알려 준다. 준 것은 친구 쪽에서 끌거나 눌러서 돌려받는다 |
| 🚌 딱 맞게 태워요 | 버스나 기차가 정류장에 오면 빈자리만큼 기다리는 친구를 눌러 고른다. 누를 때마다 "하나, 둘, 셋" 하고 세고 고른 친구는 위로 뜨며 노랗게 칠해지지만, 자리에는 아직 앉지 않는다. **출발!**을 눌렀을 때 고른 수가 빈자리 수와 같아야 친구들이 한 명씩 앉고 출발한다. 빈자리가 몇 개인지는 숫자로 보여 주지도 말하지도 않는다(첫 도움 단계는 노란 빛으로 누를 친구를 알려 줌) (아래 참고) |
| 🎠 빙글빙글 | 아홉 놀이가 차례로 바뀌는 모드. 아이의 관심이 식기 전에 장면을 바꿔 준다 (아래 참고) |

### 🎠 빙글빙글이 놀이를 바꾸는 기준

- 순서는 톡톡 세기 → 숫자 따라 누르기 → 딱 맞게 태워요 → 몇 개일까? → 거품 팡팡 → 딩동 엘리베이터 → 냠냠 먹이 주기 → 숫자 찾기 → 쏙쏙 나눠 주기. 집중이 많이 필요한 놀이(숫자 따라 누르기·몇 개일까·딩동 엘리베이터·숫자 찾기) 사이에 친구를 눌러 가며 노는 놀이를 하나씩 끼워 긴장과 이완이 번갈아 오게 했고, 버튼을 누르는 두 놀이(숫자 따라 누르기·딩동 엘리베이터), 탈것이 나오는 두 놀이(딱 맞게 태워요·딩동 엘리베이터), 딱 맞게 주는 세 놀이(딱 맞게 태워요·먹이 주기·나눠 주기)는 서로 붙지 않게 떨어뜨려 놓았습니다. 다음에 열면 지난번 다음 놀이부터 이어집니다.
- 놀이는 항상 라운드가 끝난 축하 직후에만 바뀝니다(라운드 도중에 끊지 않음). 칭찬 말이 끝날 때까지 기다렸다가 넘어가고, 그동안 놀이 화면은 다음 라운드를 시작하지 않고 멈춰 있습니다. 넘어가는 조건은 다음과 같고, 부모님 설정에서 빠르기(2번·1분 30초 / 3번·2분 30초 / 5번·4분)를 고를 수 있습니다.
  - 기본: 정해진 횟수만큼 성공 + 최소 시간(보통 1분). 푹 빠져서 잘하고 있을 때 너무 일찍 끊지 않되, 정해진 횟수보다 2번 더 성공하면 그때는 넘어갑니다.
  - 톡톡 세기·거품 팡팡은 세기만 하면 무조건 성공이라 최소 시간 없이 빠르게 넘어갑니다(빠르게 1번 / 보통 2번 / 천천히 3번 성공).
  - 정해진 시간(보통 2분 30초)이 지나면 성공 횟수가 모자라도 다음 성공 직후에 넘어갑니다.
  - 두 번 어려워하면(오답·과식·힌트 등 실패 신호) 다음에 성공하자마자 넘어갑니다. 성공한 기분으로 끝내고 장면을 바꿉니다.
  - 45초 동안 아무것도 안 누르면 흥미를 잃은 것으로 보고 "다른 놀이 해 볼까?" 하며 바꿉니다(놀이 안의 두 번째 힌트보다 늦게).
  - 막 누르기가 반복돼 라운드가 끝나지 않아도 5분이 지나면 넘어갑니다.
- 바뀔 때는 병아리가 "이번엔 거품 팡팡!" 하고 다음 놀이 아이콘이 튀어나오는 전환 화면이 나옵니다. 말이 끝나면 **시작!** 버튼이 나오고, 눌러야 다음 놀이가 시작됩니다(앞 단계 소리와 겹치지 않음). 10초 동안 안 누르면 저절로 시작합니다. 놀이 중에는 위쪽에 순서 띠(현재 놀이와 성공 횟수)가 보입니다. 띠를 길게 누르면 바로 다음 놀이로 갑니다.

- 숫자는 1부터 20까지 다룹니다. 문제를 푸는 놀이(몇 개일까·먹이 주기·숫자 찾기·딩동 엘리베이터·숫자 따라 누르기·나눠 주기·딱 맞게 태워요)마다 단계가 따로 있고, 4번 연속 성공하면 한 단계 올라가고 3번 연속 어려워하면 내려갑니다(`LEVEL_RULES`).
  - 틀리거나 힌트(15초쯤 가만히 있을 때 다시 알려 주기, 정답 깜빡임·노란 빛, 같이 세기 등. `HINT_WAIT_MS`, 숫자 찾기·몇 개일까는 셀 것이 많으면 조금 더 기다림)를 받은 라운드는 끝까지 해내면 화면에서는 똑같이 칭찬하고 별을 주지만, 단계에는 어려워한 것(실패)으로 칩니다. 실패는 한 라운드에 여러 번 틀려도 한 번만 셉니다(모든 놀이 같음).
  - 톡톡 세기·거품 팡팡: 문제를 푸는 단계가 없어서(세기만 하면 끝나므로) 따로 단계를 두지 않고, 몇 개일까 · 먹이 주기 · 숫자 찾기 · 나눠 주기에서 지금 나오는 **가장 큰 수**에 맞춥니다. 거품 팡팡은 그 수까지 세고, 톡톡 세기는 그 수 이하에서 냅니다(5를 넘으면 위쪽 60% 정도).
  - 먹이 주기: 8단계 (1~3 → 1~4 → 1~5 → … → 11~19)
  - 몇 개일까?: 다른 놀이보다 어려워서 14단계로 잘게 나눴습니다. 보기 2개 → 3개, 범위 1~3 → 10~19, 마지막 단계는 정답과 1~2 차이 나는 "비슷한 수"만 보기로 나옵니다.
  - 딩동 엘리베이터: 10단계. 2~3층 → 2~5층 → 2~7층 → … → 2~19층 → 2~20층으로 한 단계에 두 층씩 늘고, 그 단계에서 새로 생긴 두 층이 합쳐서 2번에 1번(한 층에 4번에 1번) 목적지로 나옵니다(나머지 층은 남은 절반을 고르게 나눔. 첫 단계는 2·3층이 고르게, 마지막 단계는 새로 생긴 20층만 4번에 1번). 소리만 듣고 누르며, 두 번 틀리거나 한참 가만히 있으면 그때만 정답 버튼의 노란 빛과 말풍선 숫자로 도와줍니다. 톡톡 세기·거품 팡팡이 따라가는 "가장 큰 수"에는 넣지 않습니다.
  - 나눠 주기: 7단계. 아이가 가진 개수가 2 → 3 → 5 → 7 → 10 → 15 → 20개로 늘고, 친구는 1개부터 가진 개수까지 아무 수나 달라고 합니다. 한 라운드에서 처음 "다 줬어요"를 눌렀을 때 수가 안 맞으면 어려워한 것으로 봅니다. 한참 가만히 있으면 친구가 다시 달라고 하거나 병아리가 "다 줬으면 초록 버튼을 눌러 줘!" 하고 알려 줍니다(버튼이 두근두근). 수를 맞춰야 끝나는 놀이라 아래의 막 누르기 검사는 하지 않습니다.
  - 숫자 찾기: 10단계. 엘리베이터처럼 1~3 → 1~5 → 1~7 → 1~9로 한 단계에 숫자 두 개씩 늘고, 10을 넘으면 열 개 범위를 두 칸씩 밀어 올립니다(2~11 → 4~13 → 6~15 → 8~17 → 10~19, 마지막은 10~19 "비슷한 수"). 그 단계에서 새로 나온 두 수가 합쳐서 2번에 1번(하나에 4번에 1번) 문제로 나옵니다(첫 단계와 "비슷한 수" 단계는 고르게). 문제는 보고 찾기(말풍선에 숫자를 보여 줌, 1~5까지) → 듣고 찾기(소리만, 1~7부터 섞임) → 세어서 찾기("다섯 개를 뜻하는 숫자", 1~9부터 섞임) 순서로 늘고, 흩어진 숫자는 2개에서 9개까지 늘어납니다. 소리가 비슷한 1(일)과 2(이), 11(십일)과 12(십이)는 한 판에 같이 나오지 않습니다. 두 번 틀리거나 한참 가만히 있으면 정답이 살짝 커졌다 작아지며 힌트를 줍니다.
  - 딱 맞게 태워요: 9단계. 쏙쏙 나눠 주기와 같은 단계를 10까지만 쓰고, 그 앞에 도움 단계를, 뒤에 먼저 탄 친구가 있는 세 단계를 둡니다. 정류장에서 기다리는 친구가 나눠 주기의 가진 개수처럼 2(도움) → 2 → 3 → 5 → 7 → 10명이고, 빈자리는 1개부터 그 수까지 아무 수나 나옵니다(빈자리와 친구 수가 같으면 모두 탑니다).
    - 먼저 탄 친구가 있는 단계(끝의 세 단계): 다른 친구가 먼저 몇 자리에 앉아 있어서 남은 자리만큼만 태웁니다. 정류장 친구 5명 · 자리 3~5개 중 1~2자리 → 7명 · 5~7개 중 1~3자리 → 10명 · 8~10개 중 2~4자리가 먼저 차 있습니다(늘 한 자리는 비어 있음). 먼저 탄 친구는 아무 자리에나 앉아 있고, 정류장에 없는 동물이라 헷갈리지 않습니다. 안내는 "먼저 탄 친구가 있어요! 남은 자리만큼 태워 줘!"이고, 빈자리를 같이 세어 줄 때도 먼저 탄 친구 자리는 빼고 셉니다. 태운 친구는 비어 있는 자리에 앞에서부터 앉습니다. 빈자리가 1~2개뿐인 단계는 바로 앞과 같은 수도 나와서 "하나, 둘" 번갈아 나오지 않습니다.
    - 도움 단계: 수는 1단계와 같고, 말은 보통 단계와 같게 짧게 하는 대신 노란 빛으로 알려 줍니다. 빈자리가 노랗게 칠해지고, 정류장에서는 빈자리만큼의 친구(아무 자리에서나 고름) 둘레에 노란 빛이 두근거려서 아이가 그 친구를 자연스럽게 누릅니다. 빈자리만큼 다 고르면 출발 버튼도 노랗게 빛납니다. 노란 빛은 힌트로 치지 않고, 이 단계에서는 빈자리를 같이 세어 주는 긴 안내도 하지 않습니다(틀리면 많은지 적은지만 짧게).
    - 한 라운드에서 처음 출발을 눌렀을 때 수가 안 맞거나 다시 알려 주는 힌트를 받으면 어려워한 것으로 봅니다. 톡톡 세기·거품 팡팡이 따라가는 "가장 큰 수"에는 넣지 않습니다.
  - 숫자 따라 누르기: 9단계. 누를 자리 수로 나눕니다(가장 큰 수에는 영향을 주지 않음).
    1. 두 자리 + 다음에 누를 버튼이 노랗게 빛남
    2. 두 자리
    3. 세 자리
    4. 세 자리 + 별·샵이 꼭 하나
    5. ~ 9. 네 자리 → 다섯 → 여섯 → 일곱 → 여덟 자리 (별·샵이 절반쯤 하나 섞임)

### 📱 숫자 따라 누르기

- 위에 누를 번호가 크게, 그 아래에 누른 번호가 들어가는 칸이 자리마다 맞춰 있고, 맨 아래는 전화기 키패드(1~9 / 별·0·샵 / 전화·지우기)입니다. 버튼 숫자 색과 위쪽 번호 색이 같아서 색으로도 찾을 수 있습니다.
- 번호는 한 자리씩 읽습니다. 두 자리는 "일과 이를 눌러줘!", 세 자리부터는 "일, 이, 삼을 눌러줘!". 0은 "영", \*은 "별", #은 "샵". 누를 때마다 진짜 전화기 버튼 소리(DTMF)와 함께 그 숫자 이름을 말해 주고, 말풍선을 누르면 다시 들려줍니다.
- 틀린 버튼을 누르면 그 숫자가 빨갛게 칸에 들어가고 지우기 버튼이 빛나며 "어? 다른 버튼이네! 지우기를 눌러 볼까?" 합니다. 지울 때까지 다음 숫자는 받지 않습니다. 두 번 틀리면 다음 버튼을 노랗게 알려 줍니다.
- 다 누르면 초록 전화 버튼이 두근거리고, 누르면 따르릉 소리 뒤에 동물 친구(모은 스티커 동물도)가 "여보세요? 나 토끼야! 전화해 줘서 고마워!" 하고 받습니다. 번호를 다 누르기 전에 누르면 "아직 다 안 눌렀어!" 하고 다음 버튼을 노랗게 알려 줍니다.
- 15초 동안 아무것도 안 누르면 지금 할 일(다음 숫자 / 지우기 / 전화 버튼)을 다시 알려 줍니다.
- 수가 5개를 넘으면 5개씩 줄을 맞춰 보여 줘서 묶어 세기 연습이 됩니다.
- 안내 음성이 나오는 동안(👂 표시)에는 눌러도 세지 않고, 세는 탭 사이에는 최소 간격(기본 0.7초, 설정에서 조절)이 있어 막 눌러서는 진행되지 않습니다.
- 막 눌러서 끝낸 라운드는 별을 주지 않고 거북이가 "천천히, 하나씩!" 하고 같은 라운드를 다시 냅니다.
- 효과음과 한국어 음성 안내를 켜고 끌 수 있습니다. 음성은 Gemini TTS 로 미리 만든 파일을 쓰고, 파일이 없으면 브라우저 TTS 로 읽습니다 (아래 "음성 만들기").
- 레벨이 올라가면 🚀 "우와, 더 큰 숫자 도전!" 배지가 잠깐 뜹니다. 내려갈 때는 조용히 바뀝니다.

### 🚌 딱 맞게 태워요

- 숫자 없이도 "같은 개수"를 알아보는지 보는 놀이입니다. 빈자리가 몇 개인지는 화면에 숫자로 쓰지도, 말로 하지도 않습니다(첫 도움 단계는 노란 빛으로 누를 친구를 알려 줌). 아이는 빈자리와 친구를 직접 비교하거나 세어서 맞춥니다.
- "빵빵! 버스가 왔어요!"(또는 "칙칙폭폭! 기차가 왔어요!") → "빈자리에 딱 맞게 친구를 골라 줘!" 하면 정류장의 친구를 누릅니다. 부탁은 놀이에 들어와 첫 판에만 하고(먼저 탄 친구가 있는 부탁은 그런 판이 처음 나올 때만), 다음 판부터는 "빵빵! 버스가 왔어요!"만 해서 버스가 서면 금방 누를 수 있습니다. 말풍선에는 부탁이 늘 보입니다. 누를 때마다 "하나, 둘, 셋" 하고 고른 수를 세고, 고른 친구는 위로 살짝 뜨며 발판이 노랗게 칠해집니다. 다시 누르면 내려오고 남은 수를 다시 셉니다.
- 고르는 동안에는 자리에 아무도 앉지 않습니다. 누르는 만큼 자리가 차는 걸 보고 맞추지 않도록, **출발!**을 눌렀을 때만 수를 맞춰 봅니다.
  - 딱 맞으면 고른 친구가 한 명씩 버스 아래쪽으로 건너가 자기 자리 창문에 쏙 올라와 앉으며 "하나, 둘, 셋" 하고 셉니다(한 자리에 한 친구씩. 창문 줄 위로 날아가지 않아서 이미 앉은 친구와 겹쳐 보이지 않습니다). 다 탄 버스를 잠깐 보여 준 뒤 "딱 맞아요! 친구 세 명!" 축하가 뜨고 "부릉부릉, 출발!" 하며 떠납니다. 다음 버스가 오면 새 친구들이 기다립니다.
  - 많으면 "친구가 너무 많아요! 자리가 모자라요!", 적으면 "빈자리가 남았어요! 친구가 더 탈 수 있어요!" 하고 많은지 적은지만 알려 줍니다(몇 명 차이인지는 말하지 않음).
  - 두 번 안 맞으면(도움 단계 빼고) 병아리가 "빈자리를 같이 세어 볼까?" 하고 빈자리를 하나씩 노랗게 비추며 세어 준 뒤 "친구도 똑같이 골라 줘!" 합니다.
- 빈자리는 한 줄에 다섯 자리씩이고, 다섯을 넘으면 두 줄이 됩니다(2층 버스·2층 기차).
- 15초 동안 아무것도 안 누르면 할 일을 다시 알려 주고(골랐으면 "다 골랐으면 출발 버튼을 눌러 줘!" 하며 버튼이 두근두근), 또 가만히 있으면 빈자리를 같이 셉니다(도움 단계는 할 일만 다시 알려 줌). 버스를 누르면 부탁을 다시 들려줍니다.
- 정류장에는 동물 친구들과 모은 스티커 동물 친구가 섞여서 기다립니다.

### 🛗 딩동 엘리베이터

- 동물 친구 스티커북 순서대로 한 층에 한 친구씩 늘 같은 층에 삽니다: 1층 병아리(로비) · 2층 사자 · 3층 토끼 · 4층 판다 · 5층 여우 · 6층 개구리 · 7층 코알라 · 8층 유니콘 · 9층 문어 · 10층 펭귄 · 11층 나비 · 12층 돌고래 · 13층 공룡 · 14층 거북이 · 15층 홍학 · 16층 고래 · 17층 부엉이 · 18층 호랑이 · 19층 소 · 20층 돼지. 복도 문패에도 그 친구 얼굴이 있습니다.
- 손님은 늘 1층에서 탑니다. "사자가 탔어요!" → 손님이 "이 층 눌러 주세요!" → 누르면 문이 닫히고 표시판이 한 층씩 올라가며 "일, 이" 하고 센 뒤 딩동, "이 층입니다!", 손님이 내려서 "우리 집이다! 고마워!" → 1층으로 슝 내려와 다음 손님.
- 10층 이상으로 올라갈 때는 한 낱말씩 끊지 않고 "일 이 삼 … 십", "십일 십이 … 십오" 를 이어서 빠르게 셉니다(15층까지 약 9초, 20층까지 약 12초). 표시판도 그 말에 맞춰 올라갑니다. 10층보다 낮을 때와 내려갈 때는 한 층씩 천천히 셉니다.
- 틀린 층을 누르면 그 층까지 실제로 가서(더 위로 갔으면 내려오며 거꾸로 셉니다) 그 층 친구가 인사하고, 손님이 "여기가 아니에요!" 하고 다시 부탁합니다. 엘리베이터는 그 층에서 다시 출발합니다.
- 버튼판은 진짜 엘리베이터처럼 1층이 맨 아래이고 위로 갈수록 큰 수입니다. 단계가 올라가도 버튼 자리가 바뀌지 않게 1~10층이 왼쪽에 세로 한 줄로 서고, 10층이 넘는 단계에서는 그 오른쪽에 11~20층 줄이 붙습니다. 아직 못 가는 층은 음영 버튼으로 보입니다(세로가 짧은 화면에서는 다섯 층씩 두 줄).
- **외우기**: 다섯 번 이상 집에 데려다 준 친구는 가끔(1/10) 층을 말하지 않고 "우리 집에 데려다 줘!" 합니다. 한참 가만히 있거나 틀리면 "우리 집은 오 층이에요!" 하고 알려 줍니다. 외우기 문제에서 틀리거나 층을 알려 준 것은 단계를 내리는 실패로 치지 않습니다(성공으로도 치지 않음). 노란 빛으로 알려 주면 실패로 칩니다.
- 손님을 누르면 부탁을 다시 들려줍니다.

## 자체 제작 그림과 리액션

- 캐릭터·물건·배경 소품은 이모지 대신 코드로 그린 SVG 입니다(`src/art`). 기기마다 모양이 같고, 눈·입·팔·날개를 따로 움직여 표정이 바뀝니다.
  - 병아리: 누른 곳을 쳐다보고, 안내할 땐 말하는 입, 정답이면 파닥파닥 폴짝, 틀리면 갸우뚱, 오래 가만히 있으면 꾸벅꾸벅.
  - 먹이 주기 동물: 기다릴 땐 입을 벌리고, 먹이가 입으로 날아가면 냠냠, 배가 조금씩 불러 오고, 너무 많으면 볼이 빵빵.
  - 셀 물건: 물건마다 움직임이 달라요(사과 통통, 자동차 부릉, 물고기 파닥, 꽃 활짝 …). 세면 웃고, 셀수록 반짝이가 많아집니다.
  - 장면: 흘러가는 구름, 해·달, 나무·바구니·해바라기·조개·게를 누르면 반응합니다(세기와는 상관없음).
  - 스티커 친구 72종(동물·탈것·숲속), 거품 속 바다 친구, 놀이 아이콘과 버튼·안내 표시(홈·귀·손가락·스티커북·설정 등)까지 모두 그림입니다.
- 데이터에는 이모지를 적고, 화면은 `Glyph` 로 그립니다. `src/art/registry.ts` 에 등록된 이모지는 모든 화면에 그림으로 나오고, 등록하지 않은 새 이모지만 이모지 그대로 나옵니다.
- `?gallery` 를 붙여 열면 모든 그림을 표정별로 볼 수 있습니다.
- 누를 때 짧은 진동(지원 기기만)은 부모님 설정에서 끌 수 있고, 기기의 "동작 줄이기" 설정을 따르면 흔들림·날아가기는 생략됩니다. 다만 움직임이 곧 놀이인 것(거품이 떠오르기, 나눠 주기에서 먹이가 친구 쪽으로 건너가기, 딱 맞게 태워요에서 친구가 자리로 옮겨 타기)은 그 설정에서도 돌거나 커지지 않고 조용히 움직입니다.

## 흥미를 이어 가는 장치

- **축하가 매번 달라요**: 컨페티 · 풍선 날리기 · 별비 · 하트 중 하나가 돌아가며 나오고, 칭찬 말도 13가지입니다. 가끔(약 1/6) **보너스 별**이 떠서 별을 2개 받습니다.
- **뽀로로와 친구들이 놀러 와요**: 어느 놀이에서든 맞히면 10번에 1번쯤, 늘 오는 병아리 대신 뽀로로 · 크롱 · 에디 · 루피 · 포비 · 해리 · 패티 중 한 친구(방금 온 친구는 빼고)가 화면 왼쪽이나 오른쪽에서 깡충깡충 들어와 이름 말풍선과 하트를 띄우고 3초쯤 같이 기뻐하다 돌아갑니다(해리는 날아서 둥실둥실). 스티커 선물을 받는 판은 선물이 주인공이라 오지 않습니다.
  - 놀이 안에서도 10판에 1판쯤(`PORORO_ROUND_CHANCE`) 뽀로로 친구가 나옵니다.
    - 쏙쏙 나눠 주기: 손님으로 와서(이름표가 붙음) "뽀로로가 놀러 왔어!" 하고 좋아하는 것을 달라고 합니다: 뽀로로 물고기 · 크롱 사과 · 패티 새우 · 루피 쿠키 · 에디 포도 · 포비 딸기 · 해리 꽃. 인사는 그 음성 파일이 있을 때만 합니다(없으면 기계 목소리가 섞이므로 건너뜀).
    - 딱 맞게 태워요: 버스·기차 정류장에 뽀로로 친구들이 줄을 섭니다(일곱 명보다 많이 필요하면 나머지는 늘 오는 친구들).
    - 톡톡 세기 · 몇 개일까: 뽀로로 친구들을 셉니다("뽀로로 친구 몇 명?", "뽀로로 친구 세 명!"). 한 명씩 다른 친구가 섞여 서고, 일곱 명을 넘으면 다시 처음부터.
    - 딩동 엘리베이터: 뽀로로 친구가 1층에서 타서("뽀로로가 탔어요!") 그 층 친구네 집에 놀러 가고, 도착하면 "친구네 집이다! 고마워!" 합니다. 외우기 문제는 내지 않고, 외우기에 쓰는 데려다 준 횟수에도 세지 않습니다.
    - 숫자 따라 누르기: 뽀로로 친구가 전화를 받습니다("여보세요? 나 뽀로로야! 전화해 줘서 고마워!").
  - 그림은 Glyph 로 어디서든 쓸 수 있게 `pororo:이름` 열쇠로 등록되어 있습니다(`PORORO_GUESTS`).
  - 캐릭터의 권리는 원작사에 있고, 수익을 내지 않는 조건으로 쓰기로 허락받았습니다 — 광고나 유료 기능을 붙이면 빼야 합니다.
  - 개발 서버에서 주소에 `?friends` 를 붙이면 맞힐 때마다 놀러 오고 놀이 안에서도 매판 뽀로로 친구가 나오며, `?gallery` 맨 위에서 일곱 친구의 표정을 볼 수 있습니다.
- **별 항아리**: 숫자 대신 다음 스티커까지 별 3칸이 차오르고, 한 칸 남으면 빈 칸이 두근거립니다.
- **빈 곳을 눌러도 반짝**: 버튼이 아닌 곳을 누르면 반짝이·꽃이 피어나고 작은 소리가 납니다(세기와는 상관없음).
- **놀이마다 다른 장면**: 과수원(톡톡) · 피크닉(몇 개일까) · 농장(먹이 주기) · 바닷가(거품) · 저녁 하늘(숫자 찾기) · 마을(엘리베이터) · 민트빛 하늘(숫자 따라 누르기) · 꽃밭(나눠 주기) · 정류장(딱 맞게 태워요).
- **스티커 친구가 같이 놀아요**: 가장 최근에 받은(또는 스티커북에서 고른) 친구가 놀이 화면 왼쪽 아래에서 구경하다가 성공하면 박수를 칩니다. 모은 동물 친구는 먹이 주기·나눠 주기에 손님으로 찾아오고("사자가 놀러 왔어!"), 딱 맞게 태워요의 정류장에서도 기다립니다.
- **스티커북 꾸미기**: 스티커를 누르면 위쪽 장면에 폴짝 붙고(최대 10), "같이 세기"를 누르면 붙인 친구를 하나씩 셉니다.
- 새 스티커 친구는 한 단계씩 나옵니다: 칭찬이 끝나면 🎁 선물 상자와 "선물이 왔어요! 눌러 봐!" → 말이 끝나면 상자를 누를 수 있고, 누르면 새 친구와 이름 → 이름을 다 말하면 **확인** 버튼 → 눌러야 다음 라운드(빙글빙글이면 다음 놀이)로 넘어갑니다. 그동안 뒤의 놀이는 멈춰 있습니다. 버튼이 나온 뒤 10초 동안 아무도 누르지 않으면 저절로 다음 단계로 넘어갑니다.
- **스티커북 3권**: 동물 친구 → 탈것 친구 → 숲속 친구 (모두 72개). 다 모으면 별 3개마다 스티커가 하나씩 **반짝이 스티커**로 바뀝니다.
- **기억하는 인사**: 다시 오면 "어제 만난 여우가 기다리고 있었어!", 오늘 모은 별도 홈에 보여 줍니다.
- **놀이 시간 알림**(부모 설정, 기본 끔 · 10/15/20분): 시간이 되면 다음 성공 직후에 "오늘은 여기까지! 내일 또 만나" 화면에서 오늘 모은 별과 새 친구를 보여 줍니다.

### 음성 만들기 (Gemini TTS · OpenRouter)

앱이 말하는 모든 문장은 `src/lib/phrases.ts` 에 모여 있고(약 2,900문장), 아래 명령으로 음성 파일을 만듭니다.

```bash
GEMINI_API_KEY=... npm run voice:gen   # public/voice/*.mp3 + src/lib/voice-manifest.json
npm run voice:check                    # 빠진 음성 확인
```

- `OPENROUTER_API_KEY` 가 있으면 OpenRouter(`/api/v1/audio/speech`)로 같은 Gemini TTS 를 불러 만듭니다(하루 요청 한도 없음, 사용량만큼 과금). 모델은 `OPENROUTER_TTS_MODEL`(기본 `google/gemini-3.8-flash-tts`)로 바꿀 수 있습니다.
  ```bash
  OPENROUTER_API_KEY=... npm run voice:gen
  ```
- 키는 환경 변수로만 넘기고 파일에 저장하지 마세요.
- 이미 만든 문장은 건너뛰므로 중간에 멈춰도 다시 실행하면 이어서 만듭니다. 문장을 고치면 그 문장만 다시 만듭니다.
- 모델은 `GEMINI_TTS_MODEL`(비우면 가장 최신 TTS 모델), 목소리는 `GEMINI_VOICE_NARRATOR`(병아리) · `GEMINI_VOICE_ANIMAL`(동물 손님)로 바꿀 수 있습니다.
- 자주 나오는 짧은 말은 앱과 함께 미리 받아 두고, 나머지는 한 번 들으면 오프라인에서도 재생됩니다.

기록(별, 스티커, 레벨, 설정, 꾸민 장면, 오늘 기록)은 브라우저 `localStorage` 에만 저장되며 서버로 보내지 않습니다.
