# 🎈 숫자 놀이터

두세 살 아이와 함께 **하나, 둘, 셋** 을 세어 보는 한국어 수 세기 놀이입니다.
벌점이 없고, 틀리면 병아리가 같이 다시 세어 줍니다. 라운드를 마칠 때마다 별을 모으고, 별 3개마다 새 동물 스티커 친구가 찾아옵니다.

**👉 바로 놀기: https://boboseong.github.io/toddler-counting-game/**

폰이나 태블릿에서 열고 "홈 화면에 추가" 하면 전체 화면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.

## 놀이

| 놀이 | 내용 |
| --- | --- |
| 🍎 톡톡 세기 | 물건을 하나씩 누르며 센다 |
| 🔢 몇 개일까? | 물건 개수를 보고 숫자를 고른다 |
| 🐰 냠냠 먹이 주기 | 동물이 달라는 만큼 먹이를 준다 (최고 레벨에서는 "다 줬어요"까지) |
| 🫧 거품 팡팡 | 올라오는 거품을 터뜨리며 5 · 7 · 10까지 센다 |

- 숫자 범위는 아이의 성공/실패에 따라 1~3 → 1~4 → 1~5로 자동 조절됩니다.
- 안내 음성이 나오는 동안(👂 표시)에는 눌러도 세지 않고, 세는 탭 사이에는 최소 간격(기본 0.7초, 설정에서 조절)이 있어 막 눌러서는 진행되지 않습니다.
- 막 눌러서 끝낸 라운드는 별을 주지 않고 거북이가 "천천히, 하나씩!" 하고 같은 라운드를 다시 냅니다.
- 효과음과 한국어 음성 안내(브라우저 TTS)를 켜고 끌 수 있습니다.
- 홈 화면 오른쪽 아래 **"부모님용 · 길게 누르기"** 를 1.5초 누른 뒤 덧셈 문제 두 개를 이어서 풀면 설정이 열립니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run build      # dist/
npm run deploy     # gh-pages 브랜치로 배포 (GitHub Pages)
```

React 19 · Vite 7 · Tailwind CSS 4 · Framer Motion · vite-plugin-pwa

기록(별, 스티커, 레벨, 설정)은 브라우저 `localStorage` 에만 저장되며 서버로 보내지 않습니다.
